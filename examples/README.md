# Built-in examples

This directory contains the recordings bundled with `csi_demo`. Dashboard
generation uses these local examples rather than data elsewhere in the
workspace.

```text
examples/
└── pine/
    ├── run/
    ├── walk/
    ├── pick/
    ├── lie/
    ├── fall/
    ├── stand/
    └── sit/
```

Future example sources should be added as sibling directories, for example
`ntu_fi/` or `custom_cfr/`.
